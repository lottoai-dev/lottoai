# LottoAI 🎯

LottoAI, yapay zeka destekli loto tahmin ve takip uygulamasıdır.

## Özellikler

- 🤖 AI destekli sayı tahmini
- 📊 Geçmiş sonuçları takip etme
- 🔔 Çekiliş bildirimleri
- 📱 Android ve iOS desteği

## Teknolojiler

- React Native (Expo)
- Supabase
- TypeScript
